# 鲸灵远程开发桥

把本机 dsh 的开发能力转发到鲸灵手机端:**查看电脑上的工作区与会话、派任务、实时看输出、逐条确认敏感工具调用**。

## 前置条件

1. 鲸灵服务器已部署并可通过 HTTPS 访问(例如 `https://www.example.com:8000/jingling`)。
2. 服务器 `.env` 里配置了桥接令牌 `BRIDGE_TOKEN`(与设备令牌分离)。

## 配置

在插件配置里填三项:

| 字段 | 说明 |
|---|---|
| `serverUrl` | 鲸灵服务器地址(可带路径前缀,如 `https://www.example.com:8000/jingling`) |
| `bridgeToken` | 服务器 `BRIDGE_TOKEN` 的值;**不填插件不启动** |
| `nodeName` | 手机端显示的电脑名称,默认主机名 |

`confirmTimeoutSec` 默认 15 秒:手机没在超时内确认,该工具调用**按拒绝处理**(fail-closed)。

## 能力

- **枚举**:工作区列表、每个工作区的会话、全部会话(含是否在运行)。
- **派任务 / 追问 / 停止**:通过 dsh 的 `agent.followup` / `steer` / `cancel`。
- **实时输出**:转发 `agent/assistant-stream` 的文本增量;思考内容单独标记。
- **工具调用确认**:注册 `approval/request` 的 answerer 并转发到手机。
  - 只接管**手机正在跟踪的会话**,本机自己的 dsh 使用不受影响;
  - 手机断线或超时时委托/拒绝,绝不默认放行。

## 已知限制

- dsh 的审批请求**不携带工具参数**(只有工具名与理由),手机端只能展示工具名与请求理由。
- 一次审批只授权一次(`allowed-once`),没有"永远允许"。
- 桥接是单向出站连接:电脑不需要开任何入站端口。
