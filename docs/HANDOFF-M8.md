# 鲸灵施工单 · M8 前端重设计(方向 A · 素净)

> 状态:设计稿,待确认后开工。
> 前置:`docs/DESIGN.md` §6(客户端设计)、`AGENTS.md`、`docs/CURRENT.md`
> 拍板:2026-11-18 用户看过三个方向(A 素净 / B 控制台 / C 书卷),选 **A**;并明确"可以动信息架构"。

## 0. 一句话目标

把现在"没有排版系统、版面装不下内容、层级靠一条灰线"的客户端,做成一套**有令牌、有组件、可长期维护**的界面:纸白底、一个强调色、真中文字体、按 8pt 栅格排布,信息按"今天/昨天/更早"分组,输入区不再和四个按钮抢地方。

## 1. 现状(实测,不是猜)

| 问题 | 证据 |
|---|---|
| 字体不受控 | `lib/main.dart` 的 `ThemeData` 只设了 `colorScheme.fromSeed(#2F6FED)`,没有 `textTheme`/`fontFamily`;`pubspec.yaml` 里没有 `fonts:`;整机手写观感来自这台手机的系统字体(状态栏同款) |
| 没有样式层 | 主题只在 `main.dart` 一处;6 个 widget + 10 个页面各自 `copyWith`,颜色/字号/间距散落在页面里,没有令牌 |
| 版面挤 | 对话页 1200px 宽下输入框仅约 390px(右侧 4 个圆形按钮),占位文案折成两行 |
| 层级弱 | 会话列表 = 标题 + 一行灰预览,无时间/分组/状态;顶栏「记忆 / 临时对话 / 电脑 / 设置」四个图标与产品名同排(用量在设置页里,不在顶栏) |

> 2026-11-18 由独立评审("照它干活的人")核对过本节与 §4:修正了顶栏图标清单,并删掉了「页内 Theme 覆盖」这条不成立的判断。

规模:UI 相关 Dart 约 5.5k 行(`lib/pages/*` 10 个 + `lib/widgets/*` 6 个)。

## 2. 目标 / 非目标

**目标**
- 建立设计令牌与主题(浅色 + 深色),所有页面只用令牌,不再出现裸 `Color(0x…)`/魔法数字。
- 内置中文字体,品牌与正文统一,不再受设备字体影响。
- 重排 5 个核心页面(会话列表 / 对话 / 输入区 / 电脑 / 设置),重画 4 个次级页(提醒 / 记忆 / 用量 / 设备)的列表样式。
- 会话列表:时间 + 分组 + 状态徽章 + 本地过滤搜索。
- 输入区:单行自适应输入 + 「＋」收纳附件/语音/相机。

**非目标(这次不做)**
- 不做全局搜索的后端能力(本版只过滤**已加载**的会话列表)。
- 不做底部导航(继续用顶栏 + 溢出菜单);若后面确认要做,单独一版。
- 不改任何协议、接口、业务逻辑;`server/` 零改动。
- 不引入第三方 UI 包(继续 `material_ui`),不引入动画库。

**反目标(做了就算失败)**
- 为了"看起来新"把功能入口藏起来或换位置导致找不到。
- 动画拖慢滚动/流式渲染(FPS 掉到 50 以下)。
- APK 因字体膨胀超过 3MB。

## 3. 设计系统(方向 A)

### 3.1 颜色

| 角色 | 浅色 | 深色 |
|---|---|---|
| `bg` 画布 | `#FAFAF8` | `#0F1113` |
| `surface` 卡片/输入 | `#FFFFFF` | `#171A1E` |
| `surfaceSunken` 悬停/分区 | `#F1F1EC` | `#1D2126` |
| `text` 主 | `#14161A` | `#E9EBEF` |
| `textSecondary` | `#5B6270` | `#A7AEBB` |
| `textMuted`(时间/占位) | `#8C93A0` | `#7B828F` |
| `accent` 品牌/主操作 | `#2F5DE3` | `#7FA0FF` |
| `accentSoft`(选中底) | `#2F5DE3` @10% | `#7FA0FF` @14% |
| `success` / `warning` / `danger` | `#1F8A56` / `#B4711B` / `#C0392B` | 同色提亮 8% |
| `border` / `borderStrong` | `#14161A` @8% / @14% | `#FFFFFF` @10% / @16% |

规则:强调色只用于**主操作**(发送、新建、选中态);状态用语义色,不用强调色;不使用阴影分层,用 1px 边框 + 表面色差。

### 3.2 字体与字号

字体:**Noto Sans SC(可变字体,子集化)**;备选 MiSans(同许可)。所有字都由 `ThemeData.textTheme` 提供,页面只允许 `theme.textTheme.*`。

| 令牌 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 28 / 1.25 | 600 | 会话列表页标题「鲸灵」 |
| `title` | 20 / 1.3 | 600 | 页面/对话标题 |
| `subtitle` | 16 / 1.4 | 600 | 分组标题、卡片标题 |
| `body` | 15 / 1.6 | 400 | 消息正文 |
| `bodyStrong` | 15 / 1.5 | 600 | 列表行标题 |
| `meta` | 12 / 1.4 | 400 | 时间、次数、副标题 |
| `mono` | 13 / 1.5 | 400 | 代码块、token 数字(`Roboto Mono` 回退) |

手写体**不引入**:品牌位用同一字体 600 + `letter-spacing: .02em`。

### 3.3 间距 / 圆角 / 动效

- 间距:4 / 8 / 12 / 16 / 20 / 24 / 32(`space.xs…xxxl`);页面左右边距 16,列表行内 12/16。
- 圆角:`sm 8`(chip)、`md 12`(输入框/按钮)、`lg 16`(卡片/气泡)、`pill 999`。
- 动效:状态切换 150ms、页面进入 220ms,`Curves.easeOutCubic`;不做位移大于 8px 的入场;尊重系统"移除动画"。

### 3.4 字体落地(已实测)

- 源:Google Fonts 的 `NotoSansSC[wght].ttf`(OFL,可变字体)。
- 用 `fonttools` 子集化:**GB2312 全字表 + ASCII + 常用标点 = 7543 字**,保留 `wght` 轴。
- **实测体积 3.61MB**(未子集 16.95MB);APK 预算按 **≤ 4MB** 算(v1.3.0 为 19.5MB)。
- 字重通过 `FontVariation('wght', …)` 精确取值(可变字体单文件),`tokens` 里统一封装;未覆盖的生僻字回退系统字体。

## 4. 信息架构

### 4.1 会话列表(重做)

```
鲸灵                                    ＋        ⋯
[ 搜索会话 ]                       ← 本地过滤,输入即筛
⚠ 电脑上有任务在跑 · 去看看          ← 有 harness 任务时出现,点进电脑页
置顶
  从零部署手册 review        18:20   📌
今天
  提醒与日程测试            11:03
  设置好了,两个提醒都在 11:03,到点会响
昨天
  从零部署手册 review        18:20
  Caddy 那段要改成子域名写法…
更早
  …
```

- `＋` = 新建对话(直接进);`⋯` 菜单收纳:**临时对话** / 记忆 / 电脑 / 用量 / 设置。临时对话是"不保存历史"的一次性会话,菜单项副标题写清楚。
- 分组顺序:**置顶 → 今天 → 昨天 → 本周 → 更早**(置顶独立成区,沿用 DESIGN 的"置顶区",不被日期分组埋掉)。
- 行:标题 `bodyStrong` + 预览 `meta`(1 行省略)+ 右侧时间 `meta`;置顶行带钉。
- **不做逐行"电脑在跑"徽章**:`conversation` 与 `harness_task` 之间没有关联字段,而本版不改协议;改成顶部一条全局横幅(数据来自客户端已有的 `harness` 状态)。
- **不做"临时对话"徽章**:列表接口默认不返回临时会话,徽章永远不会亮;临时会话的可见性只体现在菜单入口上。

### 4.2 对话页

- 顶栏:`title` 标题单行省略 + `⋯`(重命名 / 置顶 / **朗读这条回答** / 删除)。
- **自动朗读开关移到 设置 → 语音**(它是个长期偏好,设置里那句"聊天页右上角切换"的文案同步改掉);朗读进行中,在输入框上方显示一条 `meta`「正在朗读 · 停止」。
- 正文:`body` 15/1.6,左右 16;用户消息保留 accent 气泡(降低认知成本),助手消息无气泡。
- 工具痕迹:统一成一条 `meta` 行 + 可展开,不再各页自定义。

### 4.3 输入区(重做)

```
[联网搜索] [深度思考]            ← 两个 chip,可折叠成一行小字
＋  ┌────────────────────────┐  ↑
    │ 给鲸灵发消息…            │
    └────────────────────────┘
```

- 输入框占满剩余宽度,最小高 44,最多 5 行自适应。
- 「＋」打开底部动作表:语音 / 拍照 / 相册 / 文件;四个圆形按钮消失。
- **发送钮是一个三态按钮**(不能把它变成纯灰禁用,否则生成中就没法中断):
  - `idle` 且输入为空 → 40% 灰、点不动;
  - `idle` 且有输入 → accent + ↑;
  - `generating` → 变 **■ 停止**,点它中断本轮(等价于现在顶栏那个停止)。

### 4.4 电脑页 / 设置页 / 次级页

- 全部改用统一 `AppBar`(标题左对齐 `title`,返回箭头 44×44)与统一列表行组件(`leading 20` / 标题 `bodyStrong` / 副标题 `meta` / 右侧值或箭头)。
- 设置页分组:通用 / 服务器 / 更新 / 数据;每组一张卡片(`surface` + `lg` 圆角),行间 1px `border` 分隔。
- 空状态统一组件:一个 24px 图标 + 一行 `subtitle` + 一行 `meta`。

## 5. 组件与文件

```
lib/design/
  tokens.dart          // 颜色/字号/间距/圆角/动效常量(唯一来源)
  theme.dart           // buildLightTheme() / buildDarkTheme()

    top_bar.dart       // 统一 AppBar(标题 + 可选主操作 + 溢出)
    list_row.dart      // leading/title/subtitle/trailing/status
    status_pill.dart   // 电脑在跑 / 临时 / 置顶
    section_header.dart
    empty_state.dart
    composer.dart      // 输入区(含 ＋ 动作表、chips)
    segmented_chips.dart

```

迁移时逐页替换,旧的内联样式删除;`tokens.dart` 之外不允许出现十六进制颜色(加一条测试断言扫描 `lib/` 里的 `Color(0x`)。

## 6. 迁移顺序(每步独立可验收)

1. **地基**:tokens + theme + 字体子集化 + 接入 `main.dart`(浅/深)。
2. **会话列表**:分组 + 搜索 + 状态胶囊 + 顶栏 `＋`/`⋯`。
3. **对话页 + 输入区**:正文排版、顶栏、Composer(含 ＋ 动作表、chips)。
4. **电脑页 + 设置页**:统一 AppBar/分组卡片/列表行。
5. **次级页**:提醒、记忆、用量、设备、配对页。

每步跑 `flutter analyze` + `flutter test`,并截图对比(真机 24129PN74C)。

## 7. 验收清单

1. `flutter analyze` 零 issue、`flutter test` 全绿(现有 48 条 + 新增)。
2. 新增测试:①分组纯函数(置顶/今天/昨天/本周/更早);②`tokens` 之外无裸颜色(扫描 `lib/`);③Composer 三态(空输入禁用 / 有输入可发 / 生成中显示停止且点击触发中断);④`⋯` 菜单包含全部入口。
3. 真机:会话列表有置顶区/分组/时间;搜索输入即筛;对话页顶栏只有标题 + ⋯;输入区单行不折行,＋ 能开语音/拍照/相册/文件;生成中点 ■ 能中断;`⋯` 里"朗读这条"能播、顶部出现"正在朗读·停止";有 harness 任务时列表顶部出现横幅。
4. 深色:系统切深色后所有页面可读(文字对比 ≥ 4.5:1)。
5. APK 体积增量 ≤ 4MB(v1.3.0 为 19.5MB,字体子集实测 3.61MB)。
6. 不回归:分支切换、编辑重发、重新生成、长按菜单、语音、提醒、OTA、临时对话(入口在 ⋯ 里)全部可用。

## 8. 风险

| 风险 | 处置 |
|---|---|
| 字体子集缺字(生僻字/日文/emoji) | 保留系统 fallback;子集含 CJK 常用 + 扩展 A 部分;实测常见输入 |
| 迁移期样式混用 | 按页迁移,每页合并即删旧样式;进度用 §6 顺序控制 |
| 深色对比不足 | 令牌里已给深色值,逐页截图核对 |
| 性能 | 只用隐式动画;列表用 `ListView.builder`;不做模糊/大阴影 |

## 9. 交给实现者的判断

- 字体子集的具体字符集与工具参数(用 `fonttools pyftsubset`)。
- 分组边界(周一算本周还是昨天算今天)按客户端时区,测试覆盖即可。
- 「＋」动作表的排布顺序(语音/拍照/相册/文件)。
- 旧组件(`message_bubble`/`thinking_block`/`branch_switcher`)的内部实现是否顺手重构——只要对外行为不变。
